## Resumo dos Conceitos Praticados

Durante essas atividades, aprendi os fundamentos do HTML e sua importância na estruturação de páginas para a Web. Aprendi a criar e organizar elementos HTML, utilizar atributos, compreender a estrutura básica de um documento HTML e aplicar diferentes tags para construir conteúdos.

Também pratiquei a identificação e correção de erros no código por meio de atividades de depuração, além de desenvolver uma página simples utilizando os conhecimentos adquiridos.
